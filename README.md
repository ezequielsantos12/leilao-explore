# Leilão Explore
App pessoal + robô que confere todo dia a Caixa (PA) e os sites de leiloeiros.
- `.github/workflows/robo.yml` – agenda do robô (todo dia 06:37, horário de Belém)
- `robo/robo.py` – lista oficial da Caixa
- `robo/sites.py` + `robo/sites.json` – sites dos leiloeiros (para incluir/tirar um site, edite sites.json)
- `docs/` – o app (GitHub Pages)
